# Capoeira Brasil Apps

Served at https://apps.capoeirabrasil.be via GitHub Pages. One folder per app.

- `CongoCalender/` — Congo Capoeira Calendar (CCC), read-only web version, rebuilt daily.
- `launchpad/` — app launchpad. Edit `launchpad/apps.json` to add apps (put icons in `launchpad/icons/`). Sends iPhone users to the App Store, Android users to Google Play, everyone else to the web link. `launchpad/?app=<id>` jumps straight to one app.
